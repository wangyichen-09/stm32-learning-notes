## 一、传感器介绍

### 1.1 MPU6050是什么

MPU-6050是InvenSense公司生产的六轴运动处理传感器，集成了3轴MEMS陀螺仪和3轴MEMS加速度计，是消费电子领域应用最广泛的IMU（惯性测量单元）之一。

### 1.2 功能特性

| 功能 | 说明 |
|---|---|
| **3轴加速度计** | 测量X/Y/Z三个方向的线加速度，量程可选±2g/±4g/±8g/±16g |
| **3轴陀螺仪** | 测量X/Y/Z三个方向的角速度，量程可选±250/±500/±1000/±2000 °/s |
| **温度传感器** | 芯片内部温度测量 |
| **数字运动处理器（DMP）** | 内置硬件加速器，可做9轴传感器融合 |
| **1024字节FIFO** | 降低系统功耗，支持突发读取 |

### 1.3 应用场景

- **平衡车**：测量车身姿态，实现直立控制
- **无人机**：姿态解算，飞行控制
- **智能手机**：屏幕旋转、计步、游戏控制
- **智能手环/手表**：运动监测、姿态识别
- **机器人**：运动姿态感知

## 二、硬件接线

### 2.1 引脚分配表

| MPU6050引脚 | STM32引脚 | 说明 |

| VDD | 3.3V | 电源供电 |
| GND | GND | 接地 |
| SCL | PB10 | I2C时钟线 |

| AD0 | GND | 地址选择（接GND = 从机地址0x68） |

### 2.2 注意事项

- **AD0引脚**：接GND时从机地址为0x68，接VDD时为0x69
- **供电电压**：VDD为2.375V~3.46V，接3.3V即可

## 三、I2C完整流程

### 3.1 什么是I2C

I2C（Inter-Integrated Circuit，内部集成电路总线）是Philips公司开发的两线式串行总线，用于连接微控制器和外围设备。

**两根线**：
- **SCL（Serial Clock）**：串行时钟线，由主机产生，同步数据传输
- **SDA（Serial Data）**：串行数据线，双向传输数据

**总线特点**：
- 一主多从：一个主机可以挂多个从机
- 地址寻址：每个从机有唯一的7位地址
- 半双工：同一时间只能一个方向传输
- 标准速度：100kHz / 快速模式400kHz / 高速模式3.4MHz

---

### 3.2 开漏输出 + 上拉电阻

**开漏输出结构**：

引脚内部只有一个NMOS管，漏极（D）接到引脚上，源极（S）接到GND。

- NMOS导通时：引脚被拉低到GND（输出0）
- NMOS断开时：引脚是高阻态，既不输出高也不输出低

**为什么需要上拉电阻？**

因为开漏输出拉不出高电平，所以外部必须接上拉电阻（通常4.7kΩ）到VCC：
- 当NMOS断开时，电流从VCC经上拉电阻流到引脚，把引脚"拉"到高电平
- 当NMOS导通时，引脚直接接GND，上拉电阻限流

**I2C总线为什么要用开漏？**

因为总线上有多个设备，如果用推挽输出，一个设备输出高、另一个输出低，就会短路烧坏。开漏输出不会出现这种问题——所有设备都只能拉低，高电平靠上拉电阻统一提供。

---

### 3.3 起始与停止条件

**总线空闲状态**：SCL和SDA都为高电平（被上拉电阻拉着）。

| 条件 | 时序 | 说明 |
|---|---|---|
| **起始（Start）** | SCL为高电平时，SDA由高变低（下降沿） | 告诉所有从机：我要开始通信了 |
| **停止（Stop）** | SCL为高电平时，SDA由低变高（上升沿） | 告诉所有从机：通信结束，总线释放 |
| **重复起始（Repeated Start）** | 不发Stop，直接再来一个Start | 读数据时用，不结束总线就换方向 |

**关键**：Start和Stop都是在**SCL高电平期间**SDA发生变化。数据传输时SCL高期间SDA不能变，只有Start/Stop时可以变。

---

### 3.4 数据传输时序

**铁律：SCL高时数据有效，SCL低时数据可变**

传输一个字节的过程：

```
第1步：SCL拉低，主机把数据放到SDA上（放数据窗口）
第2步：SCL拉高，从机采样SDA上的数据（采样窗口）
第3步：SCL拉低，主机换下一位
```

重复8次，就传输了一个字节（8位数据）。

**每个字节后跟一个ACK位**（第9个时钟）：
- 主机发完8位数据后，释放SDA（松手）
- 第9个SCL高期间，从机拉低SDA = ACK（应答成功）
- 从机没拉低 = NACK（不应答）

---

### 3.5 ACK应答机制

ACK（Acknowledge，应答）是I2C的握手机制。

| 阶段 | 谁控制SDA | 动作 |
|---|---|---|
| 发8位数据 | 主机 | 主机一位一位把数据放到SDA |
| 第9个时钟 | 从机 | 主机释放SDA，从机拉低SDA = ACK |

**常见ACK问题**：
- 收到NACK = 从机没响应 → 检查地址对不对、接线对不对、上电了没
- 读最后一个字节时，主机要发NACK告诉从机"读完了"

---

### 3.6 从机地址怎么来的

I2C地址是7位，MPU6050的固定地址前缀是 **b110100**（0x68的高6位）。

**第7位（bit0）由AD0引脚决定**：

| AD0引脚电平 | 7位地址 | 发送字节（左移1位） |
|---|---|---|
| 接GND（0） | 0x68 | 写：0xD0，读：0xD1 |
| 接VCC（1） | 0x69 | 写：0xD2，读：0xD3 |

**为什么要左移1位？**

因为I2C协议规定：地址是7位，第8位（bit0）是读写位（0=写，1=读）。
所以7位地址左移1位，腾出最低位放读写位。

---

### 3.7 写寄存器完整流程

写一个寄存器的完整时序：

```
1. Start：起始信号
2. 发地址+写位：0xD0（0x68 << 1，bit0=0=写）
3. 收ACK：从机应答
4. 发寄存器地址：比如0x6B（PWR_MGMT_1）
5. 收ACK：从机应答
6. 发数据：比如0x01（唤醒芯片）
7. 收ACK：从机应答
8. Stop：停止信号
```

---

### 3.8 读寄存器完整流程

读单个寄存器的完整时序：

```
1. Start：起始信号
2. 发地址+写位：0xD0（先告诉从机要读哪个寄存器）
3. 收ACK
4. 发寄存器地址：比如0x75（WHO_AM_I）
5. 收ACK
6. 重复Start：不发Stop，直接再来一个Start
7. 发地址+读位：0xD1（这次要读数据了）
8. 收ACK
9. 读数据：从机把数据放到SDA上
10. 发NACK：主机告诉从机"读完了，就这一个字节"
11. Stop：停止信号
```

**为什么读要"重复Start"？**

因为要先告诉从机"我要读哪个寄存器"（写操作），然后再读数据（读操作）。如果中间发了Stop，从机就不知道上下文了。重复Start的作用就是"不结束总线，直接换方向"。

## 四、驱动代码实现

### 4.1 软件架构（三层设计）

驱动采用三层分层设计，从上到下：

```
┌─────────────────────────────────┐
│  应用层（MPU6050读写寄存器）      │  ← 直接操作芯片
├─────────────────────────────────┤
│  协议层（I2C时序函数）           │  ← 按I2C协议控制电平
├─────────────────────────────────┤
│  引脚层（GPIO读写）              │  ← 最底层，操作硬件
└─────────────────────────────────┘
```

| 层级 | 作用 | 包含函数 |
|---|---|---|
| **引脚层** | 最底层，直接操作GPIO | Init / W_SCL / W_SDA / R_SDA |
| **协议层** | 按I2C协议产生时序 | Start / Stop / SendByte / ReceiveByte / SendAck / ReceiveAck |
| **应用层** | 针对MPU6050的操作 | WriteReg / ReadReg / ReadRegs / Init |

---

### 4.2 引脚层（4个函数）

#### MyI2C_Init — 初始化I2C引脚

```c
void MyI2C_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);  // 开启GPIOB时钟
	
	GPIO_InitTypeDef GPIO_InitStruct;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_OD;          // 开漏输出模式
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_10 | GPIO_Pin_11; // PB10=SCL, PB11=SDA
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;         // 速度50MHz
	GPIO_Init(GPIOB, &GPIO_InitStruct);                   // 初始化GPIO
	
	GPIO_SetBits(GPIOB, GPIO_Pin_10 | GPIO_Pin_11);      // 默认高电平（释放总线）
}
```

---

#### MyI2C_W_SCL — 写SCL电平

```c
void MyI2C_W_SCL(uint8_t BitValue)
{
	GPIO_WriteBit(GPIOB, GPIO_Pin_10, (BitAction)BitValue);  // 写PB10电平
	Delay_us(10);  // 延时10us，控制时序速度
}
```

---

#### MyI2C_W_SDA — 写SDA电平

```c
void MyI2C_W_SDA(uint8_t BitValue)
{
	GPIO_WriteBit(GPIOB, GPIO_Pin_11, (BitAction)BitValue);  // 写PB11电平
	Delay_us(10);  // 延时10us
}
```

---

#### MyI2C_R_SDA — 读SDA电平

```c
uint8_t MyI2C_R_SDA(void)
{
	uint8_t BitValue;
	BitValue = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11);  // 读PB11实际电平
	Delay_us(10);  // 延时10us
	return BitValue;  // 返回读到的电平
}
```

---

### 4.3 协议层（6个函数）

#### MyI2C_Start — 起始信号

```c
void MyI2C_Start(void)
{
	MyI2C_W_SDA(1);  // ① SDA先置高
	MyI2C_W_SCL(1);  // ② SCL置高
	MyI2C_W_SDA(0);  // ③ SCL高期间SDA拉低 = 起始信号
	MyI2C_W_SCL(0);  // ④ SCL拉低收尾
}
```

---

#### MyI2C_Stop — 停止信号

```c
void MyI2C_Stop(void)
{
	MyI2C_W_SDA(0);  // ① SDA先置低
	MyI2C_W_SCL(1);  // ② SCL置高
	MyI2C_W_SDA(1);  // ③ SCL高期间SDA拉高 = 停止信号
}
```

---

#### MyI2C_SendByte — 发送一个字节

```c
void MyI2C_SendByte(uint8_t Byte)
{
	uint8_t i;
	for(i = 0; i < 8; i++)  // 循环8次，发8位数据
	{
		MyI2C_W_SDA(Byte & (0x80 >> i));  // 取出bit7~bit0放到SDA（从高位开始）
		MyI2C_W_SCL(1);                     // SCL高：从机采样数据
		MyI2C_W_SCL(0);                     // SCL低：换下一位
	}
}
```

---

#### MyI2C_ReceiveByte — 接收一个字节

```c
uint8_t MyI2C_ReceiveByte(void)
{
	uint8_t i, Byte = 0x00;
	MyI2C_W_SDA(1);  // 先释放SDA（松手），让从机控制数据线

	for(i = 0; i < 8; i++)  // 循环8次，读8位数据
	{
		MyI2C_W_SCL(1);  // SCL高：从机把数据放到SDA上
		if(MyI2C_R_SDA() == 1)  // 读到1就拼进对应位
		{
			Byte |= (0x80 >> i);
		}
		MyI2C_W_SCL(0);  // SCL低：从机换下一位
	}
	return Byte;  // 返回读到的字节
}
```

---

#### MyI2C_SendAck — 发送应答位

```c
void MyI2C_SendAck(uint8_t AckBit)
{
	MyI2C_W_SDA(AckBit);  // 0=ACK（应答），1=NACK（不应答）
	MyI2C_W_SCL(1);       // SCL高：从机读应答位
	MyI2C_W_SCL(0);       // SCL低：结束
}
```

---

#### MyI2C_ReceiveAck — 接收应答位

```c
uint8_t MyI2C_ReceiveAck(void)
{
	uint8_t AckBit;
	MyI2C_W_SDA(1);       // 释放SDA（松手）
	MyI2C_W_SCL(1);       // SCL高：读从机的应答
	AckBit = MyI2C_R_SDA();  // 读SDA：0=应答，1=不应答
	MyI2C_W_SCL(0);       // SCL低：结束
	return AckBit;  // 返回应答位
}
```

---

### 4.4 应用层（MPU6050读写函数）

#### MPU6050_WriteReg — 写单个寄存器

```c
void MPU6050_WriteReg(uint8_t reg, uint8_t data)
{
	MyI2C_Start();               // ① 起始信号
	MyI2C_SendByte(0x68 << 1);  // ② 发设备地址+写位（0xD0）
	MyI2C_ReceiveAck();          // ③ 等从机应答
	MyI2C_SendByte(reg);         // ④ 发寄存器地址
	MyI2C_ReceiveAck();          // ⑤ 等从机应答
	MyI2C_SendByte(data);        // ⑥ 发数据
	MyI2C_ReceiveAck();          // ⑦ 等从机应答
	MyI2C_Stop();                // ⑧ 停止信号
}
```

---

#### MPU6050_ReadReg — 读单个寄存器

```c
uint8_t MPU6050_ReadReg(uint8_t reg)
{
	uint8_t data;
	
	MyI2C_Start();               // ① 起始信号
	MyI2C_SendByte(0x68 << 1);  // ② 发设备地址+写位
	MyI2C_ReceiveAck();          // ③ 等从机应答
	MyI2C_SendByte(reg);         // ④ 发寄存器地址
	MyI2C_ReceiveAck();          // ⑤ 等从机应答
	
	MyI2C_Start();               // ⑥ 重复起始（不发Stop直接换方向）
	MyI2C_SendByte(0x68 << 1 | 1);  // ⑦ 发设备地址+读位（0xD1）
	MyI2C_ReceiveAck();          // ⑧ 等从机应答
	
	data = MyI2C_ReceiveByte();  // ⑨ 读数据
	MyI2C_SendAck(1);            // ⑩ 发NACK（读完了，就这一个字节）
	MyI2C_Stop();                // ⑪ 停止信号
	
	return data;  // 返回读到的数据
}
```

---

#### MPU6050_ReadRegs — 连续读多个寄存器

```c
void MPU6050_ReadRegs(uint8_t reg, uint8_t *buf, uint8_t len)
{
	uint8_t i;
	
	MyI2C_Start();               // ① 起始信号
	MyI2C_SendByte(0x68 << 1);  // ② 发设备地址+写位
	MyI2C_ReceiveAck();          // ③ 等从机应答
	MyI2C_SendByte(reg);         // ④ 发起始寄存器地址
	MyI2C_ReceiveAck();          // ⑤ 等从机应答
	
	MyI2C_Start();               // ⑥ 重复起始
	MyI2C_SendByte(0x68 << 1 | 1);  // ⑦ 发设备地址+读位
	MyI2C_ReceiveAck();          // ⑧ 等从机应答
	
	for(i = 0; i < len; i++)  // 循环读len个字节
	{
		buf[i] = MyI2C_ReceiveByte();  // 读一个字节存到buf
		if(i < len - 1) MyI2C_SendAck(0);  // 前面的发ACK（继续读）
		else MyI2C_SendAck(1);             // 最后一个发NACK（结束）
	}
	
	MyI2C_Stop();  // 停止信号
}
```

### 5.2 PWR_MGMT_1（0x6B）— 唤醒芯片

**数据手册**：RM 4.36 节

**位定义**：

| 位 | 名称 | 说明 |
|---|---|---|
| bit7 | DEVICE_RESET | 设备复位，写1复位后自动清零 |
| bit6 | SLEEP | 睡眠模式，1=睡眠，0=唤醒 |
| bit5 | CYCLE | 周期模式 |
| bit4 | TEMP_DIS | 温度传感器禁用，1=禁用 |
| bit[2:0] | CLKSEL | 时钟选择 |

**配置值：0x01**

| 位 | 值 | 说明 |
|---|---|---|
| bit7 | 0 | 不复位 |
| bit6 | 0 | 唤醒（退出睡眠） |
| bit5 | 0 | 不用周期模式 |
| bit4 | 0 | 温度传感器开启 |
| bit[2:0] | 001 | 选择X陀螺PLL时钟（更稳定） |

---

### 5.3 SMPLRT_DIV（0x19）— 采样率配置

**数据手册**：RM 4.4 节

**公式**：采样率 = 1kHz / (1 + SMPLRT_DIV)

**配置值：0x09**

采样率 = 1000Hz / (1 + 9) = 100Hz

## 六、数据读取与换算

### 6.1 数据寄存器映射

**数据手册**：RM 4.2~4.13 节

从0x3B开始连续14个寄存器，存放加速度、温度、陀螺仪数据：

| buf下标 | 寄存器地址 | 寄存器名称 | 数据内容 |
|---|---|---|---|
| buf[0] | 0x3B | ACCEL_XOUT_H | 加速度X高8位 |
| buf[1] | 0x3C | ACCEL_XOUT_L | 加速度X低8位 |
| buf[2] | 0x3D | ACCEL_YOUT_H | 加速度Y高8位 |
| buf[3] | 0x3E | ACCEL_YOUT_L | 加速度Y低8位 |
| buf[4] | 0x3F | ACCEL_ZOUT_H | 加速度Z高8位 |
| buf[5] | 0x40 | ACCEL_ZOUT_L | 加速度Z低8位 |
| buf[6] | 0x41 | TEMP_OUT_H | 温度高8位 |
| buf[7] | 0x42 | TEMP_OUT_L | 温度低8位 |
| buf[8] | 0x43 | GYRO_XOUT_H | 陀螺仪X高8位 |
| buf[9] | 0x44 | GYRO_XOUT_L | 陀螺仪X低8位 |
| buf[10] | 0x45 | GYRO_YOUT_H | 陀螺仪Y高8位 |
| buf[11] | 0x46 | GYRO_YOUT_L | 陀螺仪Y低8位 |
| buf[12] | 0x47 | GYRO_ZOUT_H | 陀螺仪Z高8位 |
| buf[13] | 0x48 | GYRO_ZOUT_L | 陀螺仪Z低8位 |

---

### 6.2 数据拼接方法

每个传感器的16位数据拆成高8位和低8位两个寄存器存放。

拼接方法：**高8位左移8位 + 低8位**

```c
int16_t AccX = (buf[0] << 8) | buf[1];  // 加速度X
int16_t AccY = (buf[2] << 8) | buf[3];  // 加速度Y
int16_t AccZ = (buf[4] << 8) | buf[5];  // 加速度Z

int16_t GyroX = (buf[8] << 8) | buf[9];   // 陀螺仪X
int16_t GyroY = (buf[10] << 8) | buf[11]; // 陀螺仪Y
int16_t GyroZ = (buf[12] << 8) | buf[13]; // 陀螺仪Z
```

### 6.3 灵敏度换算

**数据手册**：PS Electrical Characteristics 节

#### 加速度灵敏度

| 量程 | 灵敏度（LSB/g） |
|---|---|
| ±2g | 16384 |
| ±4g | 8192 |
| ±8g | 4096 |
| ±16g | 2048 |

**换算公式**（±2g量程）：
```c
float accX_g = AccX / 16384.0f;  // 单位：g
float accY_g = AccY / 16384.0f;
float accZ_g = AccZ / 16384.0f;
```

---

#### 陀螺仪灵敏度

| 量程 | 灵敏度（LSB/(°/s)） |
|---|---|
| ±250°/s | 131 |
| ±500°/s | 65.5 |
| ±1000°/s | 32.8 |
| ±2000°/s | 16.4 |

**换算公式**（±250°/s量程）：
```c
float gyroX_dps = GyroX / 131.0f;  // 单位：°/s
float gyroY_dps = GyroY / 131.0f;
float gyroZ_dps = GyroZ / 131.0f;
```

### 6.4 温度换算

**数据手册**：RM 4.2 节

**换算公式**：
```c
int16_t temp_raw = (buf[6] << 8) | buf[7];  // 读原始值
float temp_c = temp_raw / 340.0f + 36.53f;   // 单位：°C
```

### 6.5 完整读取代码

```c
void MPU6050_Read_Data(float *accX, float *accY, float *accZ,
                      float *gyroX, float *gyroY, float *gyroZ)
{
	uint8_t buf[14];
	int16_t AccX, AccY, AccZ;
	int16_t GyroX, GyroY, GyroZ;
	
	// 连续读14个字节（从0x3B开始）
	MPU6050_ReadRegs(MPU6050_ACCEL_XOUT_H, buf, 14);
	
	// 拼接加速度数据
	AccX = (buf[0] << 8) | buf[1];
	AccY = (buf[2] << 8) | buf[3];
	AccZ = (buf[4] << 8) | buf[5];
	
	// 拼接陀螺仪数据
	GyroX = (buf[8] << 8) | buf[9];
	GyroY = (buf[10] << 8) | buf[11];
	GyroZ = (buf[12] << 8) | buf[13];
	
	// 换算成实际值
	*accX = AccX / 16384.0f;  // 加速度单位：g
	*accY = AccY / 16384.0f;
	*accZ = AccZ / 16384.0f;
	
	*gyroX = GyroX / 131.0f;   // 陀螺仪单位：°/s
	*gyroY = GyroY / 131.0f;
	*gyroZ = GyroZ / 131.0f;
}
```
