- ⚙️ **寄存器配置**：从数据手册定位寄存器、理解位定义、配置量程
- 📊 **数据读取与换算**：14字节数据拼接、灵敏度换算公式

## 🔌 硬件接线

| MPU6050引脚 | STM32引脚 | 说明 |
|---|---|---|
| VDD | 3.3V | 电源供电 |
| GND | GND | 接地 |
| SCL | PB10 | I2C时钟线 |
| SDA | PB11 | I2C数据线 |
| AD0 | GND | 从机地址 = 0x68 |

> ⚠️ SDA/SCL 需要外接 **4.7kΩ上拉电阻** 到3.3V

## 🚀 快速开始

1. 用 Keil MDK 打开 `MPU6050/MPU6050模块复刻/Project.uvprojx`
2. 按硬件接线表连接 STM32 与 MPU6050
3. 编译下载（F7编译 → F8下载）
4. 调试运行，读 WHO_AM_I 寄存器应返回 `0x68`

## 🧠 学习路线（我的过程）

1. **读手册**：查 Pin Out → 典型电路 → 数字接口 → 寄存器映射
2. **写驱动**：引脚层（GPIO）→ 协议层（I2C时序）→ 应用层（读写寄存器）
3. **验驱动**：Keil调试器读 WHO_AM_I = 0x68 ✅
4. **读数据**：连续读14字节 → 拼接16位 → 按灵敏度换算
